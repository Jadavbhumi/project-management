# Project Management

A simple web application for managing projects, tasks, teams, and workspaces in one place.

## Features

- Create and manage workspaces
- Create and manage projects
- Create, update, and delete tasks
- Assign tasks to team members
- Add comments to tasks
- Manage project members
- View project progress and analytics
- View tasks using a calendar
- User authentication
- Email functionality
- Different task statuses and priorities

## Technologies Used

### Frontend
- React
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- Clerk Authentication
- Inngest
- Nodemailer
